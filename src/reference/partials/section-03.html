For developers

Run any agent and review every change with air in ides

Track parallel work

Keep several projects open, each with its own sessions, and track unread updates, changed files, and outgoing commits in all of them.

Easily connect agents

Air finds compatible agents on your machine and lets you connect them with a click. You can also add new ones from the agent registry.

Review every change in context

Open diffs directly from an agent session, validate changes with your IDE tools, and leave comments on specific lines for the agent to act on.

Flexible AI access

Bring your existing provider subscription or API keys, or even base URL. You can also use JetBrains AI with credits billed at public API rates. Switch between subscriptions – even mid-session.
